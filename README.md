# NASA Space Facts

## Project Idea
NASA Space Facts is a simple educational application that displays interesting facts about NASA and space.

The project helps users learn basic information about planets, space, and NASA in an easy and interactive way.

## Technologies Used
- HTML
- CSS
- GitHub

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Read the NASA and space facts displayed on the webpage.
