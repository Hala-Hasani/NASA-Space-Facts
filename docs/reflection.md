# Reflection

In this lab, I learned how GitHub can be used to organize and manage a software project. I learned how to create a repository, create and manage issues, work with branches, make commits, and merge changes using pull requests.

One of the challenging parts was understanding how branches and pull requests work because I was not used to separating different parts of a project into different branches. After completing the lab, I understood how branches help keep changes organized before merging them into the main project.

The most enjoyable part was seeing the project improve after each commit and being able to track all the changes through GitHub.

If I had more time, I would improve the design of the webpage, add more NASA and space facts, and make the project more interactive.
